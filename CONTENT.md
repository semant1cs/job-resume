# Что нужно заполнить

Весь текстовый контент лежит в `src/data/*.ts`. Ничего в компонентах трогать
не нужно — просто отредактировать значения в файлах ниже (места, помеченные
`TODO`, — плейсхолдеры).

## `src/data/profile.ts` — блок "Кто я"

- `name` — имя, как будет в шапке и в hero
- `role` — должность (например, "Frontend Developer")
- `tagline` — один цепляющий подзаголовок под именем
- `bio` — 1–3 коротких абзаца о себе: опыт, что нравится в разработке
- `location` — город/страна (или формат работы)
- `availableForWork` — `true`/`false`, влияет на бейдж "Открыт(а) к предложениям" в hero

## `src/data/experience.ts` — блок "Опыт работы" (новый)

Массив мест работы, от последнего к первому. На каждую компанию:

- `company` — название
- `role` — должность
- `period` — период работы (например, "2023 — по настоящее время")
- `location` — формат (удалённо/офис/гибрид), необязательно
- `description` — 1 предложение о продукте/компании и своей роли в нём
- `highlights` — 2–4 буллета: конкретные результаты/проекты/сервисы, над
  которыми работал(а), с цифрами, если есть
- `stack` — технологии, которые использовал(а) на этом месте (необязательно)

Для дизайна ("каждый блок — один экран") лучше держать 2–4 места работы с
компактными буллетами — секция верстается как вертикальный таймлайн.

## `src/data/stack.ts` — стек технологий

Два массива объектов `{ name, icon, years? }`:

- `primaryStack` — с чем работаешь часто
- `secondaryStack` — что можешь применить при необходимости

`icon` — имя иконки из публичных коллекций Iconify (сейчас используются
`logos:*`, например `logos:vue`, `logos:typescript-icon`). Полный список
можно посмотреть на icon-sets.iconify.design → набор "Logos". Если нужной
технологии там нет — подойдёт любая другая иконка формата `набор:имя`.

## `src/data/skills.ts` — "Что я умею" + прогресс-бары

Один массив `{ name, level (0–100), description }` — используется сразу в
двух секциях (описание и анимированные бары), редактировать нужно в одном
месте.

- `level` — твоя честная самооценка в процентах, на неё завязана анимация бара
- `description` — коротко, что именно входит в этот навык

## `src/data/expectations.ts` — что жду от компании

Массив `{ title, description, icon }` — 3–5 пунктов о том, какие условия
работы для тебя важны.

## `src/data/contacts.ts` — контакты

Массив `{ type, label, value, href, icon }`. Сейчас заведены email, Telegram,
GitHub, LinkedIn — можно добавить/убрать пункты. `href` для телефона —
`tel:+7...`, для остальных — прямые ссылки.

## `src/data/facts.ts` — интересные факты о жизни

Массив `{ title, description, icon }` — 4 карточки с короткими фактами вне
работы (сейчас — про головоломки, киберспорт, спорт, системный подход).

## `src/data/achievements.ts` — вне-IT достижения

Уже заполнено реальными данными из твоего запроса (судоку, сапёр, CS2 FACEIT,
Dota 2, баскетбол, пауэрлифтинг) — просто проверь формулировки и при желании
поправь `value`/`description`/цвета (`color`, hex).
